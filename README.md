# 🐱🐶 Cat & Dog Image Classification

A CNN-based deep learning application that classifies images as **Cat** or **Dog** using TensorFlow and Keras.

## 🎥 Demo

[▶️ Watch the Demo]()

## ✨ Features

- CNN-based image classification
- Cat vs Dog binary classification
- Streamlit web interface
- Image upload and prediction
- Confidence score
- Data augmentation
- Batch normalization
- Dropout
- Early stopping

## 📊 Results

- Validation Accuracy: **88%**
- Image Size: **180 × 180**
- Optimizer: **Adam**
- Loss: **Binary Crossentropy**

## 🗂️ Dataset

Dataset used for training:

[Kaggle — Cats and Dogs Image Classification](https://www.kaggle.com/datasets/samuelcortinhas/cats-and-dogs-image-classification)

The dataset is not included in this repository due to its size.

## 🛠️ Tech Stack

`Python` `TensorFlow` `Keras` `NumPy` `Pandas` `Pillow` `Streamlit` `Scikit-learn`
